# Проверка проекта — 27 сентября 2026

Исправлены подтверждённые проблемы:

- Конкурирующие операции с ядром теперь отклоняются; запись состояния и настроек выполняется последовательно с атомарной заменой JSON.
- Остановка проверяет результат и управляет процессами по полному пути к установленному менеджером `winws.exe`. Ошибки проверки процесса больше не выглядят как успешная остановка.
- Обновление требует SHA-256, ограничивает загрузку 256 МБ, сохраняет `lists/*-user.txt`, удерживает резервную копию до проверки запуска и восстанавливает прежнюю сборку при ошибке.
- Отмена автоподбора учитывается и на последнем шаге. При отмене или отсутствии рабочего конфига восстанавливается предыдущее состояние; ложного сообщения об успехе нет.
- HTTP 4xx/5xx не считаются доступным сервисом. Неуспешные ответы исключаются из среднего отклика, медленные доступные сервисы учитываются в числе работающих.
- Добавлены проверка отправителя IPC, запрет внешней навигации и новых окон, CSP и блокировка второго экземпляра приложения.
- Обновление менеджера использует `isUpdateAvailable`, запрещает установку до загрузки и не устанавливается автоматически при обычном выходе.
- Фоновые ошибки доступны интерфейсу. Сохранение настроек подтверждается сервером; кнопки блокируются на время операций; диалоги удерживают фокус клавиатуры.
- Ошибка обращения к GitHub больше не отображается как подтверждение актуальности установленной версии.

Проверки: 30 тестов Vitest, TypeScript/Vite production build, синтаксис CommonJS и `git diff --check`. `npm audit` сообщил 0 известных уязвимостей. Тесты ядра проверяют откат на временных файлах; системные команды Windows в них заменены заглушками.

Ограничения проверки: работа проводилась на macOS. Требуется ручная проверка на Windows 10/11: запуск и остановка реального WinDivert, установка и обновление NSIS, UAC, автозапуск после входа, PowerShell и совместимость с установленной отдельно службой Zapret. Регистрация автозапуска через Windows Login Items сама по себе не подтверждает успешный запуск приложения, требующего повышения прав. Автозапуск открывает менеджер, но не включает стратегию автоматически. HTTP-пробы не проверяют воспроизведение YouTube или голосовую связь Discord. Произвольные ручные изменения файлов Flowseal, кроме `lists/*-user.txt`, при успешном обновлении заменяются.

Основание для защиты IPC и навигации: [рекомендации Electron](https://www.electronjs.org/docs/latest/tutorial/security). Поведение обновлений сверено с установленным кодом `electron-updater` и [документацией electron-builder](https://www.electron.build/docs/features/auto-update/).
